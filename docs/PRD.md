# DailyMemento 产品需求文档 (PRD)

## 一、项目概述

### 1.1 项目名称
DailyMemento - 每日小成就记录器

### 1.2 项目定位
一款轻量级的PWA应用，帮助用户记录每日生活中的小成就，培养积极的生活态度，建立个人成就感档案。

### 1.3 目标用户
- 希望培养积极心态的职场人士
- 需要记录生活点滴的个人用户
- 习惯使用手机记录生活的年轻人

---

## 二、功能需求

### 2.1 页面一：今日成就记录页

#### 功能描述
用户当天记录自己的小成就，系统建议每天记录3条，但不限制数量。

#### 核心功能
| 功能项 | 说明 |
|--------|------|
| 添加成就 | 支持输入成就内容，字数限制1-200字 |
| 成就数量提示 | 默认显示"今日目标：3条"，记录后显示进度 |
| 时间戳 | 自动记录添加时间 |
| 编辑删除 | 支持当天已记录成就的编辑和删除 |
| 快捷输入 | 提供常用成就模板（可选） |
| 鼓励反馈 | 完成3条后显示鼓励语/动画效果 |

#### 交互细节
- 成就卡片按时间倒序排列
- 空状态显示引导文案和示例
- 支持长按卡片唤起编辑/删除菜单
- 输入框支持多行文本

### 2.2 页面二：日历回顾页

#### 功能描述
以日历形式展示历史记录，用户可选择日期查看当天的成就。

#### 核心功能
| 功能项 | 说明 |
|--------|------|
| 日历视图 | 月历展示，标记有记录的日期 |
| 日期标识 | 有记录的日期显示特殊标记（如圆点） |
| 点击查看 | 点击日期弹出该日成就列表 |
| 月度切换 | 支持左右滑动切换月份 |
| 今日标记 | 高亮显示当前日期 |
| 统计信息 | 顶部显示当月记录天数统计 |

#### 交互细节
- 已记录日期用不同颜色深浅表示记录数量（可选）
- 点击空白日期显示"当天无记录"引导
- 支持快速跳转到今天
- 底部显示选中日期的成就预览

### 2.3 页面三：全部记录页

#### 功能描述
列表形式展示所有历史成就记录，支持搜索和筛选。

#### 核心功能
| 功能项 | 说明 |
|--------|------|
| 时间线列表 | 按日期分组展示所有记录 |
| 搜索功能 | 支持关键词搜索历史成就 |
| 日期筛选 | 按时间范围筛选记录 |
| 删除记录 | 支持删除历史记录（需确认） |
| 数据统计 | 显示总记录数、总坚持天数 |
| 导出功能 | 支持导出为文本/图片（可选） |

#### 交互细节
- 列表支持下拉刷新、上拉加载更多
- 日期分组折叠/展开
- 空状态显示引导文案
- 长按卡片显示操作菜单

## 三、非功能需求

### 3.1 性能要求
| 指标 | 要求 |
|------|------|
| 首屏加载 | < 2秒 |
| 页面切换 | 流畅无卡顿 |
| 离线可用 | 支持离线记录，联网后同步 |

### 3.2 体验要求
- 支持暗色模式
- 响应式设计，适配手机/平板
- 操作反馈及时（动画、提示）
- 符合PWA安装标准

### 3.3 数据要求
- 本地存储优先
- 支持数据导出/备份
- 数据隐私保护（不上传服务器）

## 四、界面原型

### 4.1 导航结构
```
┌─────────────────────────┐
│    DailyMemento         │
├─────────────────────────┤
│                         │
│      [内容区域]          │
│                         │
│                         │
├─────────────────────────┤
│  📝今日  📅日历  📋全部  │
└─────────────────────────┘
```

### 4.2 页面流程
```
启动页
  │
  ├─> 今日成就 ──────────────┐
  │      │                   │
  │      └─> 添加/编辑成就    │
  │                          │
  ├─> 日历回顾 ──────────────┤
  │      │                   │
  │      └─> 查看历史记录     │
  │                          │
  └─> 全部记录 ──────────────┘
         │
         └─> 搜索/筛选/导出
```

## 五、优先级划分

### P0（核心功能，第一期）
- 今日成就记录（增删改）
- 本地数据存储
- 基础UI布局

### P1（重要功能，第一期）
- 日历视图
- 全部记录列表
- PWA基础配置

### P2（增强功能，第二期）
- 搜索功能
- 数据导出
- 暗色模式
- 鼓励动画

### P3（未来规划）
- 云端同步
- 数据统计图表
- 分享功能
- 成就模板
