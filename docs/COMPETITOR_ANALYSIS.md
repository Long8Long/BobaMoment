### 3.2 痛点分析

**BobaMoment 当前痛点**：
1. ❌ **缺少数据可视化** - 无法看到趋势和统计
2. ❌ **无提醒功能** - 容易忘记记录
3. ❌ **无连击激励** - 缺少正向反馈
4. ❌ **无数据导出** - 本地数据无法备份/分享
5. ❌ **激励体系薄弱** - 除了进度提示外无其他激励

**竞品优势借鉴**：
- **Three Good Things**：每日固定 3 条的心理机制、极简体验
- **Daylio**：丰富的情绪图标、数据图表、PIN 保护
- **Streaks**：连击激励、健康数据集成、自定义提醒
- **Atomic Habits**：原子化习惯拆解、热力图可视化、详细统计

## 四、差异化机会

### 4.1 BobaMoment 的独特定位

**核心差异化**：
- ✅ **三类型混合记录** - 成就+感念+情绪，更全面
- ✅ **文本输入自由度** - 不受限的文本表达
- ✅ **PWA 离线优先** - 无需下载 App，即开即用
- ✅ **纯本地存储** - 隐私优先，不上传云端
- ✅ **简洁不花哨** - 专注核心功能
- ✅ **免费开源** - 长期免费使用

**目标人群**：
- 关注隐私，不愿使用云端同步的用户
- 需要 PWA 的轻量级记录者
- 希望文本自由表达的记录者
- 需要多维度记录（不仅情绪或习惯）的用户
- 追求极简但不愿放弃功能丰富度的用户

### 4.2 差异化定位策略

**与 Daylio 对比**：
- Daylio：云端同步 + 丰富图标 + 订阅制
- BobaMoment：本地存储 + 文本自由 + 免费

**与 Atomic Habits 对比**：
- Atomic Habits：打卡习惯 + 连击追踪 + 订阅制
- BobaMoment：文本记录 + 情绪深度 + 免费

**核心口号建议**：
- 原版："记录你的珍珠时刻"
- 优化后："记录感受，而非仅打卡"
- 或："深度记录，隐私优先"

```typescript
const calculateStreak = (dates: string[]) => {
  const sortedDates = [...new Set(dates)].sort().reverse()
  let streak = 0
  let currentDate = new Date()

  for (const date of sortedDates) {
    const diff = Math.floor((currentDate - new Date(date)) / (1000 * 60 * 60 * 24))
    if (diff === streak) {
      streak++
      currentDate = new Date(date)
    } else {

    }
  }
  return streak
}
```

## 七、差异化战略

### 7.1 核心差异化

**记录方式对比**：
| 产品 | 记录方式 | 深度 | 效率 |
|------|---------|------|------|
| **Atomic Habits** | 打卡 | ⭐⭐ 浅 | ⭐⭐⭐⭐⭐ 快 |
| **Daylio** | 图标选择 | ⭐⭐⭐ 中 | ⭐⭐⭐⭐⭐ 快 |
| **BobaMoment** | 文本输入 | ⭐⭐⭐⭐⭐ 深 | ⭐⭐⭐⭐ 中 |

**核心价值主张**：
```
Atomic: 我做了（打卡）
Boba: 我感受（记录）

打卡：完成，但不深入
记录：深入，理解自己
```

### 7.2 竞争策略

**对比 Daylio/Streaks/Atomic Habits**：
- ✅ 强调免费（无订阅制）
- ✅ 强调隐私（纯本地存储）
- ✅ 强调跨平台（PWA）
- ✅ 强调深度记录（文本 vs 打卡）

**对比 Three Good Things**：
- ✅ 强调功能丰富（三类型）
- ✅ 强调数据管理（日历/列表）
- ✅ 强调 PWA 优势

### 9.1 竞争格局

| 产品 | 市场定位 | 核心优势 | 核心劣势 | 差异化空间 |
|------|---------|---------|---------|-----------|
| **BobaMoment** | 轻量级隐私优先 PWA | 本地存储、多类型、PWA、免费 | 无图表、无提醒、无连击 | 🔥 需完善 |
| **Three Good Things** | 极简感恩日记 | 极简、心理学背书、免费 | 功能单一、无云同步 | 🔸 已饱和 |
| **Daylio** | 情绪追踪日记 | 图标丰富、图表强大 | 订阅制、无文本 | 🔸 已饱和 |
| **Streaks** | 习惯追踪打卡 | 连击激励、健康集成 | iOS 专有、价格高 | 🔸 已饱和 |

### 9.2 BobaMoment 的战略定位

**核心定位**：
```

│   核心价值：                            │
```
